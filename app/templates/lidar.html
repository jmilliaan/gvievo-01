Device error and application error are kept apart on purpose: a device error puts the scanner into a locking state and needs a complete restart, while an application error only needs the safety function restarted. Collapsing them into one “lidar fault” loses the operator's next action. These four are not decoded yet — the status block's layout is not in this repo.
