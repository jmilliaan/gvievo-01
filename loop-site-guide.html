Loop site: dari lantai kosong sampai satu Start, satu lap

Satu loop tape tertutup, tanpa junction, tanpa MLS marker. Petakan area, ajarkan loop dengan menjalankannya, tandai HOME dan area cepat, lalu go live: setiap Start di HOME menjalankan satu lap dan berhenti di HOME.

Persiapan

Engineer · di PC
  1. Pasang tape loop dengan radius di setiap sudut. Sebelum yang lain, jalankan satu lap biasa dengan mission c-loop-guided dan jalan di sampingnya: setiap sudut harus terlewati tanpa FAULT. Sudut yang FAULT ("no tape within 75 deg") perlu radius di lantai, bukan perubahan software.
  2. Tempel panah di lantai pada HOME, menunjuk arah jalan AGV. Panah ini adalah titik awal survey, titik awal pass pertama, dan tempat HOME diajarkan.
  3. Profile: tape_loc.site_mission: "loop-site", shadow_circuit: "C-LOOP", live: false, station.enabled: false. Restart amr.service setelah operator memberi izin.
Selesai jikaHalaman Teach menampilkan loop-site, dan Run → Calls menampilkan "A loop: no calls, no trolleys".
1

Mapping area

Selector MANUAL · halaman Mapping
  1. Parkir di atas panah, menghadap arah panah, diam. Mapping → Survey → map id (mis. loop_site), start mark "HOME arrow" → Start survey.
  2. Jalankan bagian lurus dengan preset moves: Forward sampai 10 m pada 0.30 m/s. Belok di sudut dengan preset spin (20–180°) atau jog pelan; setiap spin dibatasi 0.27 rad/s selama survey.
  3. Putari loop dua arah, di atas atau di samping tape, dan sedikit melebihi area yang akan dilewati AGV.
  4. Kembali ke panah dengan heading yang sama → Returned to start. Baca nilai closure.
  5. Save map revision → rev N.
  6. Dynamic areas (parkir trolley, rak yang berpindah) dibuat sekarang, dengan ros2 run amr_mission map_edit … --dynamic-rect …. Ini menghasilkan rev N+1: lakukan teach di revisi itu.
Setelah setiap preset move, pesan merah "the map may have slipped here" (≥ 2°): mundur dan jalankan bagian itu lagi pelan-pelan. "The map is broken from here" (≥ 5°): abort lalu mulai ulang.
Selesai jikaClosure beberapa cm dan 1–2°, dinding terlihat tunggal dan lurus, revisi sudah tersimpan.
2

Loop run (teach pass)

Selector AUTO · halaman Teach
  1. Teach → map, rev → Select map → Restart tape layer. Di atas panah: beri initial pose manual (hanya pertama kali) → Scans align → READY.
  2. Halaman Run → mission c-loop-guided. Teach: circuit C-LOOP → Record pass.
  3. Panel: AUTO → Start. AGV mengikuti tape pada 0.4 m/s. Jalan di sampingnya.
  4. Setelah AGV melewati panah: End lap (halaman Teach, atau tombol E). AGV berhenti dalam 0.5 m dan run selesai.
  5. Stop pass. Pesan: loop closed, L m.
  6. Ulangi untuk pass 2 dan 3, mulai dari tempat AGV berhenti. Tidak perlu jog kembali.
Ditolak: pass yang berakhir lebih dari 0.5 m sebelum titik awalnya, pass yang dijalankan arah sebaliknya, atau pass yang tidak melewati HOME dalam jarak 15 cm.
Selesai jikaTiga pass tersimpan, ketiga nilai L berbeda tidak lebih dari sekitar 0.2 m.

Membuat marks

MANUAL untuk parkir · halaman Teach

HOME

  1. Jog ke atas panah, dengan satu meter terakhir maju sepanjang tape (AMCL hanya update saat bergerak).
  2. Diam 3 detik → Station HOME → Teach here → Build.
Selesai jikaHOME taught on HOME:loop>HOME dalam 10 cm dari tape, dan every circuit compiles.

High-speed areas (opsional)

  1. Teach → High-speed areas → Draw new → klik sudut-sudutnya → Save. Gambar hanya di bagian lurus; tikungan tidak pernah cepat.
  2. Akhiri setiap area minimal 2 m sebelum HOME, agar AGV sudah kembali ke cruise sebelum berhenti.
  3. Publish → Make active → Restart tape layer.
Selesai jikaTeach Status menampilkan nama graph dan tile Locator menunjukkan IDLE.
5

Shadow lap

AUTO · live masih off
  1. Di atas panah: At home → Scans align → READY. Locator berubah WAITING → HEALTHY.
  2. Lima lap dengan c-loop-guided, End lap setelah panah setiap kali. Satu orang berdiri di panah dan mencatat posisi AGV saat log menampilkan stop HOME … ok.
Selesai jikaSetiap lap mencatat shadow: lap complete; tidak ada would HOLD, tidak ada LOST, tidak ada "fork with no taught junction"; Locator HEALTHY sepanjang putaran, termasuk saat melewati HOME; titik HOME di log dalam ±10 cm dari panah.
6

Siap jalan

Engineer sekali · lalu operator
  1. Profile tape_loc.live: true, restart setelah operator memberi izin.
  2. At home dikonfirmasi otomatis di HOME (auto_confirm_home).
  3. Selector AUTO → Start: horn 2 detik, satu lap pada 0.5 m/s (lebih cepat hanya di dalam area yang digambar), measured stop di HOME, run selesai.
  4. Start lagi untuk lap berikutnya. Tidak ada tombol lain.
Ukur lima stop pertama terhadap panah, sepanjang tape: target ±10 cm, dan tidak bergeser dari lap ke lap. Stop hanya bergantung pada map; bagian kosong tanpa dinding/rak sebelum HOME membuatnya kurang presisi.
Start di luar HOME ditolak ("not at HOME"). Jog dulu kembali ke panah.
